Módulos del Ciclo ASIX

Estos son los módulos de primer curso del ciclo de Administración de Sistemas Informáticos en Red.

Volver a la página principal

Descripción de los módulos

Tutoría (TT)

Reuniones con el tutor del grupo para el seguimiento de las notas, organizar las entregas del curso y preparar las futuras prácticas en empresas (FCT o FP Dual).

Fundamentos de Hardware (HW)

Prácticas en el taller: desmontar torres, identificar componentes, testear fuentes de alimentación, cambiar módulos de RAM, discos SSD y aprender a solucionar los típicos fallos cuando un ordenador no arranca.

Implantación de Sistemas Operativos (SS)

Instalación en entornos virtuales de sistemas Linux y Windows. Aprenderás a dominar la terminal de comandos (CLI), gestionar usuarios, dar permisos a archivos y automatizar tareas pesadas mediante scripts.

Bases de Datos (BD)

Diseño y creación de bases de datos desde cero. Se aprende a programar en lenguaje SQL utilizando sistemas reales para insertar, modificar y extraer información mediante consultas complejas.

Implantación de Aplicaciones Web (IPW)

Montaje y puesta en marcha de servidores web (como Apache o Nginx). Instalación y configuración de gestores de contenido como WordPress y despliegue de aplicaciones para que funcionen correctamente en la nube.

Planificación y Administración de Redes (IPO)

Configuración física y lógica de una red. Aprenderás a grimpar cables Ethernet, conectar switches y programar routers reales para gestionar el tráfico de datos de una oficina.

Fundamentos de Programación (PROG)

El primer contacto con el código. Desarrollo de programas lógicos utilizando estructuras de control, bucles y variables para aprender a pensar como un programador y automatizar la administración de sistemas.

Servicios de Red e Internet (SE)

Configuración de los servicios indispensables de Internet: servidores encargados de traducir nombres web (DNS), asignación automática de direcciones IP (DHCP), transferencia de archivos (FTP) y correo electrónico.

Inglés Técnico (ANG)

Clases enfocadas a entender manuales oficiales de servidores, interpretar mensajes de error de la consola de comandos, leer documentación técnica y redactar correos en el ámbito tecnológico.

Siglas y nombres completos

  • TT: Tutoría
  • HW: Fundamentos de Hardware
  • SS: Implantación de Sistemas Operativos
  • BD: Bases de Datos
  • IPW: Implantación de Aplicaciones Web
  • IPO: Planificación y Administración de Redes
  • PROG: Fundamentos de Programación
  • SE: Servicios de Red e Internet
  • ANG: Inglés Técnico
